# What is Aethium?

Aethium is a dynamically typed, object-oriented programming language written in Go. It is compiled to bytecode and run on its own VM. It is designed to be simple to write while still providing features for building larger and concurrent programs. It has a Python-like feel to its syntax, with support for classes, exceptions, decorators, and dynamic objects. It also includes Go-inspired concurrency features such as goroutines and channels. 

## Features of Aethium

- Simple and readable syntax [Very similar to Python]
- Object-oriented programming
- Classes, inheritance, and multiple inheritance
- C3 method resolution order
- Dynamic typing
- Operator overloading
- Exception handling
- Functions, closures, and decorators
- Iterators and generators
- Goroutines and channels
- Concurrent programming
- Garbage collection
- Modules and packages
- Foreign Function Interface (FFI)
- Go interoperability
- Bytecode compiler and virtual machine
- Interactive REPL
- Sandboxing support
- Built-in formatter and linter
- Cross-platform runtime
